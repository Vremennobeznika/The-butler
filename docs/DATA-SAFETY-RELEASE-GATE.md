# The Butler — gate изменений и автономных помощников

| ID | Проверка | Ожидание | Новый цикл |
|---|---|---|---|
| BUT-01 | JSON экспорт/импорт | Тестовый план восстанавливается без потерь | NOT VERIFIED |
| BUT-02 | Изменение хранилища | Старый план корректно мигрирует, нет сброса | NOT VERIFIED |
| BUT-03 | ICS и уведомления | Не вводят в заблуждение относительно фоновой работы iOS | NOT VERIFIED |
| BUT-04 | mac-tools | Установка/обновление/отключение LaunchAgent по документированной схеме | NOT VERIFIED |
| BUT-05 | Безопасность | Путь JSON проверяется, команды не выполняются из пользовательского содержимого | NOT VERIFIED |
| BUT-06 | Приватность | Личные данные, токены и журналы не попадают в публичную сборку/скриншоты | NOT VERIFIED |
| BUT-07 | Mobile/desktop | Существующие тесты и ручная проверка | NOT VERIFIED |

Процедура: начать с README.md, tests/ и mac-tools; зафиксировать SHA; работать в PR; `node --test tests/model.test.cjs tests/storage.test.cjs tests/butler.test.cjs` и `python tests/ui_smoke.py .` — проверить команды запуском в подходящей среде. Для Mac-помощника обязательна отдельная проверка на macOS.

Особое ограничение: данные браузера и ручной экспорт для Mac не синхронизируются автоматически; не обещать гарантированные фоновые события iOS. Сохранять явную резервную копию до импорта и переключения версий.
