# МОЯ НЕДЕЛЯ — Mac / iPhone / кошки / поесть

**Независимая версия** универсального локального планировщика. Тот же тёмный монохромный стиль: квадратные галочки, недельные вкладки, чёрные/серые поверхности, без синей темы. Никаких аккаунтов, рекламы, внешних API и облачных баз данных. Расписание и финансы сохраняются в браузере **только на конкретном устройстве**.

## Что сделано специально для Mac и iPhone

Исходные шаблоны, которые пользователь может редактировать/отключать целиком в «Настройках»:

- **Еда**: завтрак 08:30, обед 13:00, ужин 19:30. Для этих пунктов переключатели напоминаний изначально включены.
- **Кошки**: кормление утром и вечером, проверка воды, проверка лотков. Это редактируемые шаблоны, не ветеринарные рекомендации.
- **Работа за Mac**: отдельный пункт «Отойти от Mac и размяться» (в исходных настройках без напоминания).
- Покупки: собственные категории, включая «Для кошек», чекбоксы, количество и время напоминания для каждого товара.
- Финансы, недельный план, свои разделы, поиск и дублирование пунктов, скрытие разделов.

Все названия разделов, напоминания, время и дни недели задаются централизованно на **отдельной** странице «Настройки». У каждого пункта есть собственная кнопка-колокольчик. Сохраняется на одном устройстве, перенос через JSON-файл.

## Установка

**Mac:** Открыть приложение по HTTPS (после публикации статических файлов) в Safari; при желании добавить как веб-приложение. Для проверки из исходников: `python3 -m http.server 8000` и `http://localhost:8000/`.

**iPhone:** Открыть опубликованный HTTPS-сайт в Safari → Поделиться → «На экран Домой» → запустить и дать разрешение на уведомления, если браузер предлагает его. Простое добавление на домашний экран не превращает локальные JS-таймеры в системные фоновые уведомления.

**Отдельный репозиторий:**

```bash
cd apple-cats-meals
git init
git add .
git commit -m "Add offline Apple cats and meals planner"
git branch -M main
gh repo create Vremennobeznika/apple-cats-meals --public --source=. --remote=origin --push
```

GitHub CLI (`gh`) должен быть установлен и авторизован. Для размещения включить Settings → Pages → Deploy from a branch → `main` / `/ (root)`. Эти команды **не затрагивают** другие репозитории.

## Принудительное открытие вкладки: что реально возможно

- **В открытом приложении** напоминание показывает крупное окно; можно закрыть, отметить выполненным или отложить на 10 минут. При разрешении показывается системное уведомление; **нажатие по нему** возвращает на соответствующий пункт, если браузер позволяет.
- **iPhone с закрытым приложением:** без push-сервера PWA не может по расписанию самостоятельно проснуться, уведомить и тем более насильно открыть браузер. Для полностью локальных системных сигналов экспортируйте `.ics` из «Настроек» и импортируйте в Календарь. Уведомление от календаря показывается системой; оно не гарантирует открытие сайта.
- **Mac с закрытым браузером:** в `mac-tools/` есть **опциональный локальный LaunchAgent**. Он раз в минуту читает экспортированный JSON-файл, при совпадении времени вызывает Safari и пытается вывести его на передний план. Работает без сервера и внешних запросов, но доступность уведомлений и активации окна зависит от разрешений macOS. Помощник пока протестирован логически, **не на реальном Mac**.

### Установка локального помощника на Mac (необязательно)

1. На вкладке «Настройки» сохранить JSON-копию своего плана.
2. В Терминале Mac запустить `./mac-tools/install_mac.sh ~/Downloads/moya-nedelya-ДАТА.json 'https://АДРЕС-ПРИЛОЖЕНИЯ/'`.
3. После любого изменения расписания скачать свежий JSON и выполнить `./mac-tools/update_mac_data.sh ~/Downloads/НОВАЯ-КОПИЯ.json`. **Из браузера и обратно в помощник нет автоматической синхронизации** — данные остаются локальными.
4. Отключить помощник: `./mac-tools/uninstall_mac.sh`.

Нужен установленный Python 3. Помощник использует `launchd`, стандартные `open` и `osascript`; не требует администратора и не отправляет содержимое файла в интернет. Если Safari открыт, он может создать вкладку на время события. Режим проверки без открытия браузера: `python3 mac-tools/mac_reminders.py --data /путь/копия.json --state /tmp/sent.json --url 'https://example.invalid/' --dry-run`.

## Приватность, резервирование и ограничения

Данные браузера не синхронизируются автоматически между Mac и iPhone. Оба экземпляра могут иметь разные планы. Регулярно сохраняйте JSON-копии и осторожно импортируйте `.ics`: ранее импортированные записи не обновляются при изменении плана, возможны дубли. В iPhone фоновый Web Push предполагает сервер, здесь его намеренно нет. Для полного доступа к напоминаниям при закрытом браузере используйте локальный календарь или нативное приложение с разрешениями ОС.

## Проверки

`node --test tests/model.test.cjs` — unit; `python tests/ui_smoke.py .` — UI на мобильных и desktop ширинах, Playwright + Chromium. Проверены переключатели, настройки, напоминания, покупки, финансы и отсутствие горизонтальной прокрутки. Реальный Safari/iOS отдельно не проверялся.
