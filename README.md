# The Butler — локальный персональный планировщик

Универсальный планировщик бытовых задач, питания, ухода за питомцами и отдыха. Работает как статическое PWA-приложение без аккаунта, аналитики, облачных баз данных и передачи персональных данных. Публичная документация не содержит сведений о конкретном человеке; примеры задач обобщены.

## Функции

- Недельное расписание, редактируемые разделы, индивидуальные уведомления на каждый пункт.
- Отмечаемые дела, добавление разовых задач на конкретную дату и время.
- Панель «Сегодня без перегруза»: ближайшее дело, неотмеченные пункты, метки «Главное» с быстрым выполнением.
- Быстрые напоминания о перекусе и перерыве, управляемая пауза уведомлений на 1, 3 или 12 часов.
- Редактируемые шаблоны питания, ухода за питомцами, проверки воды, окончания работы и отдыха.
- Покупки, личные финансы, локальный экспорт и импорт JSON, календарный экспорт .ics.
- Тёмная монохромная тема, адаптация для мобильных устройств, офлайн-кеш после установки.
- Опциональный локальный Mac LaunchAgent открывает Safari по событиям из последней экспортированной JSON-копии.

Шаблоны — только настраиваемые примеры, а не медицинские рекомендации. Напоминаний о приёме лекарств нет. Новые шаблоны появляются после первого запуска либо сброса приложения; существующий план пользователя не перезаписывается.

## Запуск и установка

На компьютере: `python3 -m http.server 8000` в папке репозитория, затем `http://localhost:8000/`. При публикации через GitHub Pages откройте сайт по HTTPS. На iPhone: Safari → «Поделиться» → «На экран Домой».

На Mac можно установить независимый локальный помощник: скачайте резервную JSON-копию из раздела «Настройки», затем выполните `./mac-tools/install_mac.sh ~/Downloads/ИМЯ-ФАЙЛА.json 'https://АДРЕС-ПРИЛОЖЕНИЯ/'`. После изменения расписания обновляйте его данные через `./mac-tools/update_mac_data.sh ~/Downloads/НОВАЯ-КОПИЯ.json`. Отключение: `./mac-tools/uninstall_mac.sh`.

## Важные технические ограничения

- В обычном PWA **невозможно гарантированно разбудить закрытый iPhone, открыть вкладку поверх других приложений или обеспечить фоновые сигналы одним JavaScript-таймером**. Экспорт .ics позволяет использовать системный календарь, но требует самостоятельного импорта.
- Mac-помощник читает только последний вручную переданный JSON; изменения в браузере автоматически не синхронизируются.
- При импорте календаря возможны дубли, а изменение расписания не удаляет уже импортированные события.
- Данные хранятся локально в браузере и могут быть потеряны при очистке данных сайта. Делайте JSON-резервные копии.
- Пауза уведомлений действует на живое приложение и на Mac-помощник **после** экспорта обновлённой копии. Она не удаляет уже импортированные календарные события.

## Проверки

`node --test tests/model.test.cjs` и `python tests/ui_smoke.py .` (нужны Playwright и Chromium). Дополнительные функции требуют проверки на реальном Safari/iOS и macOS; успешное выполнение unit-тестов не означает, что системные ограничения iOS сняты.

## Лицензирование и приватность

В приложении нет встроенной учётной записи, слежения за использованием и загрузки исходных публикаций/личных файлов. Изменения в исходном коде и документации не содержат персональных сведений исследуемого человека.
