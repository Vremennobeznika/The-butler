## Аудит устойчивости — 22 октября 2026

- Исправлено разрушительное перезаписывание повреждённого localStorage при старте. При сбое сохранение блокируется, а повреждённая запись доступна для выгрузки.
- Добавлены регрессионные тесты `tests/storage.test.cjs` на чтение и сохранение локальных данных.
- Поддерживается миграция старого поля `date` в `oneOffDate` для разовых задач, включая Mac-помощник; добавлены проверки миграции.
- Увеличены сенсорные области нажатия кнопок, обновлена версия офлайн-кеша.
- Подтверждён успешный GitHub Actions для коммита fb0db6a.
- Остаётся не проверенным на физических устройствах: Safari/macOS, iOS-уведомления, фактическое открытие Safari скриптом и офлайн-установка PWA.
